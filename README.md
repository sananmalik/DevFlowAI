# DevFlow AI

DevFlow AI is an autonomous multi-agent software development platform that simulates a complete software company using AI agents. Instead of relying on a single AI assistant, DevFlow AI creates a team of specialized agents that collaborate through **Band** to transform a software idea into an approved development plan.

The project demonstrates real agent-to-agent communication, structured task handoffs, collaborative decision-making, and workflow orchestration.

## The Problem

Software development involves multiple stakeholders: Product Managers, Software Architects, Developers, QA Engineers, and Release Managers. Each performs different responsibilities and passes work to the next stage.

Traditional AI systems usually operate as isolated assistants and cannot effectively coordinate complex software delivery processes involving reviews, approvals, and multiple decision points. Organizations need systems where multiple AI agents can collaborate similarly to real software teams.

## Our Solution

DevFlow AI creates a virtual software company. Each agent has a specific role and responsibility, and agents communicate through Band instead of directly with one another. This creates a transparent, traceable, and scalable collaboration workflow.

## Core Agents

### Product Manager Agent
Receives project requirements from the user and:
- Analyzes user requirements
- Identifies business objectives
- Defines project scope
- Creates functional requirements
- Generates feature lists

The output is published to Band.

### Architect Agent
Designs the technical solution by:
- Analyzing requirements
- Designing system architecture
- Selecting technologies
- Defining APIs
- Designing the database schema

The architecture plan is published to Band.

### Developer Agent
Converts architecture into implementation plans:
- Creates API specifications
- Generates service structures
- Creates controller designs
- Generates code skeletons

Results are published back to Band.

### QA Agent
Reviews work generated by previous agents:
- Reviews architecture
- Reviews generated code
- Validates business rules
- Detects missing requirements
- Suggests improvements

If problems exist, QA sends feedback through Band.

### Release Manager Agent
Performs the final evaluation:
- Verifies approvals
- Validates workflow completion
- Prepares release documentation
- Generates deployment readiness reports

## Agent Collaboration Through Band

Band acts as the communication layer. Instead of direct agent-to-agent calls (e.g., Product Manager → Architect), agents communicate through Band:

```
User
  ↓
Product Manager → Band
                    ↓
                 Architect → Band
                                ↓
                            Developer → Band
                                          ↓
                                        QA → Band
                                               ↓
                                       Release Manager
```

This ensures:
- Decoupled architecture
- Shared context
- Transparent communication
- Workflow traceability

## System Workflow

1. User submits a project idea (e.g., "Build a Library Management System")
2. Product Manager Agent generates requirements
3. Architect Agent creates technical design
4. Developer Agent creates implementation plan
5. QA Agent performs validation
6. Release Manager generates final approval
7. Results are displayed on the dashboard

## Database Design

### Projects
Stores project information: `ProjectId`, `Name`, `Description`, `Status`, `CreatedAt`

### AgentMessages
Stores communications exchanged between agents: `MessageId`, `ProjectId`, `AgentName`, `MessageType`, `Content`, `CreatedAt`

### AgentTasks
Stores delegated work items: `TaskId`, `ProjectId`, `AssignedAgent`, `Status`, `Description`, `CreatedAt`

### AgentExecutions
Stores execution history: `ExecutionId`, `ProjectId`, `AgentName`, `Result`, `CreatedAt`

## Technology Stack

- **Backend:** ASP.NET Core, C#
- **Database:** SQL Server, Entity Framework Core
- **Agent Framework:** Band
- **Testing:** Postman
- **Frontend:** React (Planned)

## Key Innovation

The key innovation is not the AI models themselves — it's the collaborative workflow. Agents share context, delegate work, review outputs, perform approvals, and coordinate decisions through Band, creating a true multi-agent environment instead of a collection of isolated AI assistants.
